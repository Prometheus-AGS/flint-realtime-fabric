## Requirements
### Requirement: Dart SDK docs MUST reflect the actual generator

The Dart SDK's `pubspec.yaml` and `GENERATED.md` MUST describe the SDK as generated by
`uniffi-bindgen-dart` (not flutter_rust_bridge, which is not used), and MUST accurately
describe the current known limitation of the generated async transport surface.

#### Scenario: pubspec does not credit flutter_rust_bridge

- **WHEN** a reader inspects `sdks/dart/pubspec.yaml`
- **THEN** the description names uniffi-bindgen-dart and `flutter_rust_bridge` is not a
  dependency
- **AND** `dart pub get` still resolves

#### Scenario: GENERATED.md describes the real limitation

- **WHEN** a reader consults GENERATED.md's known-limitation section
- **THEN** it matches the regenerated frf.dart (connect declares Future but throws
  UnsupportedError) and points to the shim resolution path
